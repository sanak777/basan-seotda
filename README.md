# 바카라산악회 실시간 10인 섯다

- 바이인: ₩3,000,000
- 최대 10명 실시간 착석
- 좌석, 닉네임, 캐릭터, 카드, 베팅, 보유금 서버 동기화
- 같은 브라우저의 새 창에서도 기존 좌석 자동 복귀
- 일시적인 연결 끊김은 60초 동안 좌석·보유금·패 보존
- 베팅 중 이탈자는 20초 후 자동 다이 처리하여 게임 진행 유지
- BGM 기본 음량 5%, 음소거 및 수동 음량 조절
- 매 베팅 15초 제한, 미응답 시 자동 다이
- 미베팅 10회 누적 시 자동 탈락, 최후의 1인 우승
- 모바일 통신이 잠시 끊겨도 좌석·닉네임·보유금 유지 및 자동 재접속
- 게임 시작 후 신규 중도 착석 차단(기존 참가자의 재접속은 허용)
- 미착석 이용자는 언제든 관전 모드로 입장(베팅 권한 없음)
- Admin 로그인 후 착석 좌석 클릭 → 확인 후 강퇴
- 관리자 활성화 후 일반 참가자 화면에서 Admin 버튼 숨김
- 선 다음 좌석부터 순서대로 진행되는 베팅 레이스와 현재 차례 강조
- 체크·콜·따당·하프·다이 한국어 딜러 음성 및 돈뭉치 효과음
- 한 판 종료 후 다음 판 자동 진행
- 4·9 / 9·4 구사 시 기존 판돈을 유지한 재경기
- 구사 재경기에서는 참가비 재차감 없음, 올인(₩0) 생존자도 끝까지 패를 받아 판돈 경쟁
- 관리자 비밀번호: 8959
