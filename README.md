# 바카라산악회 실시간 10인 섯다

- 바이인: ₩3,000,000
- 최대 10명 실시간 착석
- 좌석, 닉네임, 캐릭터, 카드, 베팅, 보유금 서버 동기화
- 같은 브라우저의 새 창에서도 기존 좌석 자동 복귀
- 일시적인 연결 끊김은 60초 동안 좌석·보유금·패 보존
- 베팅 중 이탈자는 20초 후 자동 다이 처리하여 게임 진행 유지
- BGM 기본 음량 5%, 음소거 및 수동 음량 조절
- 매 베팅 15초 제한, 미응답 시 자동 다이
- 미베팅 10회 누적 시 자동 탈락, 최후의 1인 우승
- 관리자 활성화 후 일반 참가자 화면에서 Admin 버튼 숨김
- 관리자 비밀번호: 8959
